What this is

A fast, searchable index of trial papers, past HSC papers and school assessment tasks — organised Subject → Year → School, split HSC (NESA past papers) vs Trial (school-written).

The site hosts no PDFs itself: every download resolves to its source — the community mirrors HSC Portal and PapersDB, the Board of Studies archive, and official NESA links. Catalogue metadata mirrors THSCOnline.

🐢 Slow-route papers exist only behind THSC's rate-limited resolver; they're hidden by default (sidebar toggle to show). Select papers to download individually or as a ZIP.

Tips

Share a filtered view with a link — search & filters sync to the URL (e.g. ?q=ruse&type=trial).

📖 Read opens papers in the embedded reader with a study timer. Where a source blocks cross-site reading, use ⭳ instead.

Prefer a desktop library with queued, resumable, direct-to-folder downloads? ⭳ Get the HSCPapers desktop app.
