How file hosting works

Papers are not stored in this repo. Every download button links to your remote file host:

  1. Upload PDFs to your host (R2 / S3 / VPS / Drive-mirror) keeping the folder names from data/papers.json.
  2. Set FILE_HOST_BASE_URL in js/config.js to your host.
  3. Add new papers by appending entries to data/papers.json — the UI (search, filters, counts, ZIP) updates automatically.

Single-file downloads are plain links (no CORS needed). “Download ZIP” fetches via JavaScript, so enable Access-Control-Allow-Origin: * on the host for that button.

Organisation (THSCOnline mirror)

Subject → Year → School, split by HSC (NESA past papers) vs Trial (school-written). Each entry can carry a solutionPath so papers + solutions travel together in selections and ZIPs.

Tip: share a filtered view with a link — search & filters sync to the URL (e.g. ?q=ruse&type=trial).
